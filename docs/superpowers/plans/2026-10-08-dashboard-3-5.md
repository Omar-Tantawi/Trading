# Minimal Read-only Dashboard (Sub-project 3.5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tb dashboard` serves a local, read-only page with candle charts, model evaluation charts and data health.

**Architecture:** New `dashboard/` package: `queries.py` (DB reads), `svg.py` (server-side charts), `app.py` (FastAPI routes via `create_app(connect)`), and static HTML/JS/CSS with vendored Lightweight Charts v5.2.1.

**Tech Stack:** Python 3.13, FastAPI, uvicorn, psycopg 3, Lightweight Charts 5.2.1 (vendored), pytest, Playwright (smoke test only).

**Spec:** `docs/superpowers/specs/2026-10-08-dashboard-3-5-design.md`

## Global Constraints

- Bind `127.0.0.1` only; default port 8050.
- Read-only: no route writes to the database.
- Symbols validated against `get_settings().symbols`, timeframes against `FEATURE_TIMEFRAMES`, before SQL.
- `bars`: default 500, 50 ≤ N ≤ 5,000.
- No external URL in `index.html`; no advice words (buy, sell, long, short, enter, exit) in page text or labels.
- Times shown in UTC and labelled so.

## Review Focus

1. **A symbol with no candles or no features yet** → empty chart and a message, not a 500 → test in Task 2.
2. **Run whose metrics lack reliability bins or per_fold entries** (old/partial runs) → SVG with "no data", not a crash → test in Task 1.
3. **Path tricks in model names** (`/api/runs/1/calibration/..%2Fx.svg`) → 404 → test in Task 3.
4. **Database down** when the page loads → JSON 503 with a message the page shows → test in Task 3.
5. **Large `bars` on 5m** → capped by validation (422) → test in Task 3.
